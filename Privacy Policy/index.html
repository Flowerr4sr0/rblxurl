Privacy Policy

Open Source

Roblox URL Shortener is designed to generate shortened Roblox URLs using a publicly documented, community-maintained URL format.

Safety and URL Format

This website uses a Roblox community-maintained URL format. The format is publicly discussed on the Roblox Developer Forum. It is not an official Roblox service.

You can view the original community discussion here:

Roblox Developer Forum – Unofficial ShortBlox URL Shorteners

Information Collection

The URL generator does not require an account, password or personal information to generate URLs.

Data Storage

Roblox IDs and usernames entered into the generator are used to construct the output URL. The generator does not intentionally store these values.

Third-Party Services

This website is not affiliated with or endorsed by Roblox Corporation. External Roblox links are subject to Roblox's own policies.

Important Safety Notice

Although the URL format is community-maintained and publicly documented, this does not guarantee that every destination is safe. Always check links before opening them.
